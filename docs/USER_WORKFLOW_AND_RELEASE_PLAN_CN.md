# Workbench用户流程与发布计划

更新日期：2026-09-27

## 产品定位

Workbench用于实验前筛选。它把结构、纯组分物性、活度系数路线、SLE和冻结混合物模型连接为一条可追溯的组成曲线计算流程。输出用于判断候选是否值得实验、应优先测试哪个组成范围，以及当前结论受哪些输入来源限制。它不单独确认DES形成、相稳定性、安全性或文献新颖性。

## 当前最短使用流程

1. 输入两个组分的名称与SMILES，或加载内置百里香酚–辛酸示例。
2. 搜索本地审定物性表和sigma-profile库。
3. 检查熔点与熔化焓的来源；缺失项由用户补充实验值。完整研究环境可以显式调用冻结纯物性模型，便携版不提供未打包的模型入口。
4. 选择活度系数路线：`gamma = 1`、上传`gamma(x)`、上传两份sigma-profile，或使用库内匹配profile。
5. 计算完整组成曲线，并选择是否应用冻结B3/B4校正。
6. 查看预测最低温度、组成、输入来源和支持说明；分别导出逐组成CSV与完整JSON报告。

## v0.3.0已经完成

- 不依赖ChatGPT的Windows/Ubuntu本地便携包。
- 实验物性优先，缺失值不再被静默填充。
- 便携模式隐藏不可用的纯物性模型按钮。
- `gamma = 1`时仍可运行冻结B3校正；profile路线运行冻结B4校正。
- 配对示例检查与正式校准区间分开展示。
- 输入来源、activity route和模型版本进入导出报告。
- 逐组成曲线CSV和完整报告分开导出。

## 投稿前仍建议完成的改进

1. **快速模式与高级模式分层。** 快速模式只保留结构、四项物性、activity route和计算按钮；上传profile、手动`gamma(x)`及更新队列放入高级模式。
2. **名称/SMILES自动完成。** 当前精确结构检索对非专业用户不够友好；下一版应提供本地化合物搜索和候选确认，避免同义名或盐形式选错。
3. **批量筛选入口。** 增加CSV模板，使用户一次提交多组候选并得到可排序的温度、组成、输入完整性和支持标签。
4. **正式适用域与校准模块。** 只有当输入身份、体系类别、适用域和校准类别均通过时，界面才显示论文定义的温度/组成范围；否则保持`Not assessed`。
5. **结果比较页。** 允许并列比较2–10个候选的组成曲线与实验优先级，避免用户仅按单一最低温度排名。
6. **版本化更新。** 用户测量值保存在本地导出队列，经来源审定后进入半年或年度模型更新；公开模型不在线自动重训。

## 发布原则

- GitHub仓库是代码、便携包和版本说明的下载入口。
- 科学数据、模型定义和论文结果由`des-physics-ml-atlas`仓库管理；Workbench不复制另一套相互矛盾的结果表。
- 每个正式版本同时发布压缩包、SHA-256、变更记录和示例输出。
- 在项目取得持久DOI前，不在界面或论文中显示占位DOI。
