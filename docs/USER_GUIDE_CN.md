# DES Design Workbench 使用说明

Workbench根据两个组分及其纯物性计算组成曲线，支持理想活度路线和含活度信息的路线，并可使用配套的冻结模型进行校正。

## 先运行示例

1. 下载并解压README中的便携包，按安装说明启动程序。
2. 打开 `http://127.0.0.1:4173`，选择 **Load validated example**。
3. 检查百里香酚–辛酸的四项实验纯物性与两份σ-profile，运行计算。
4. 查看组成曲线，并分别导出逐组成CSV和完整JSON报告。

示例的留出误差只说明这一配对的测试表现，不能用作其他体系的误差范围。

## 计算自己的体系

1. 输入两个组分的名称和SMILES，核对盐形式及组分身份。
2. 搜索可用的实验物性与σ-profile。确认来源后采用匹配数据。
3. 补齐熔点和熔化焓。温度单位为K，熔化焓单位为kJ mol⁻¹。便携版需要手动补充库外缺失值；已安装相应模型及获许可权重的完整研究环境可调用纯物性预测。
4. 选择活度输入：理想 `γ = 1`、上传 `γ(x)`，或提供两份σ-profile。
5. 运行组成曲线及模型校正。理想路线使用B3；含非理想特征的路线使用B4。
6. 导出报告，保留输入来源、模型版本和计算路线。

活度曲线CSV列名为 `x,gamma1,gamma2`。σ-profile CSV列名为 `sigma,p_sigma`，两个组分须使用一致的51点网格，并提供面积和体积。

## 如何理解输出

曲线用于比较组成和确定后续实验的测试位置。程序尚未对任意新输入部署论文中的完整适用域及优化目标校准，因此这类输出的可靠性显示为 **Not assessed**，不提供未经验证的90%覆盖承诺。低预测温度不能单独确认DES形成或相态稳定性。

新测量数据可以导出供来源审定和后续版本更新；计算时不会在线重训已发布模型。
