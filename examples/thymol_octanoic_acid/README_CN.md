# 已验证示例：百里香酚–辛酸

该示例用于演示“实验纯物性 → σ-profile → 非理想 SLE → B4 校正曲线”的完整本地流程。

## 为什么选它

- 两种组分均为中性分子，处于当前模型相对可靠的化学区域。
- 四项输入均来自审定实验数据：百里香酚 `Tm = 323.65 K`、`ΔHfus = 21.773 kJ mol⁻¹`；辛酸 `Tm = 289.45 K`、`ΔHfus = 21.365 kJ mol⁻¹`。
- 两种组分均有 ORCA CPCM 表面计算得到的 51 点 σ-profile。
- 在规范化的 10 点 pair-disjoint 留出子集中，B4 的 MAE 为 `2.47 K`，最大绝对误差为 `5.85 K`。

最后一项是该体系的留出表现，不代表所有候选都能达到相同精度，也不是单个新预测的置信概率。

## 文件

- `example.json`：网页可直接读取的完整示例。
- `*_sigma_profile.csv`：可上传到工作台或其他程序的 σ-profile。
- `*_sigma_metadata.json`：面积、体积、网格与计算来源信息。
- `pair_disjoint_validation.csv`：该示例所用 10 个规范化留出点的观测值、预测值和绝对误差。

网页中的“Load validated example”会自动载入这些数据。若本地预测服务已启动，将同时运行冻结的 B4 校正；若仅打开静态网页，则仍可计算 σ-profile 驱动的物理参考曲线。
